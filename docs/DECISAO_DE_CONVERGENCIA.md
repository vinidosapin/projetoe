# Decisão de convergência

1. O Projeto E v2.39 é a base.
2. Nada do curso anterior é descartado para “caber” na BNCC.
3. A organização é acadêmica e deriva das disciplinas, campos, cursos, módulos e tópicos já existentes.
4. A BNCC serve somente para procurar lacunas e novos materiais.
5. O material encontrado pela BNCC é recolocado no lugar acadêmico correto.
6. Em Matemática, IMPA/OBMEP é a fonte principal herdada.
7. Em Física, Portal da Física OBMEP é a fonte principal herdada.
8. Brasil Escola é complementar nas Exatas quando a fonte principal já cobre o tópico.
9. O aluno vê o que está estudando; não vê códigos BNCC como estrutura do curso.
10. Não existem controles de “assistido”, “concluído” ou progresso: o sistema organiza materiais.
