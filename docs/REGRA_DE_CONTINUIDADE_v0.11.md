# Regra de continuidade — v0.11

O Projeto E v2.39 é a base do trabalho.

1. nenhum material do curso anterior é removido por causa da BNCC;
2. a organização visível é `Disciplina → campo acadêmico → módulo/subcampo → tópico → materiais`;
3. o vínculo antigo de cada material é preservado em `dados/proveniencia_topicos_v1.json`;
4. em Matemática, IMPA/OBMEP aparece antes de complementos; em Física, Portal da Física OBMEP aparece antes de complementos;
5. `dados/lacunas_materiais_academicas_v1.json` é a fila real de preenchimento;
6. a BNCC só ajuda a formular buscas para essas lacunas e não aparece na interface do estudante.
